# 3 个月医生试用计划（PRD v2.1 §44）

> 桌面 .dmg 可分发后执行。本文件是运营清单，不是代码。

## 目标

验证：**医生是否愿意把真实科研想法交给 Evidence Copilot，并改变研究决策。**

## 受试者

- **10–20 位**临床医生 / 临床科研人员
- 每人至少提交 **1 个真实科研问题**

## 时间

- **约 12 周（3 个月）**
- 第 1–2 周：安装培训（`curl | bash` 或 .dmg）
- 第 3–10 周：自由使用 + 每两周 15 分钟回访
- 第 11–12 周：问卷 + 访谈

## 记录指标（PRD §42）

| 指标 | 目标 | 记录方式 |
|---|---|---|
| Research Idea → Useful Decision Rate | ≥70% | 试用结束时 1 题问卷 |
| Return Research Rate | ≥50% | 是否提交第 2 个问题 |
| Real Project Conversion | ≥30% | 是否进入检索/初筛流程 |
| Sustained Usage（>1 月） | ≥20% | 安装后 30 天仍打开应用 |

## 必记事件

- 提交的研究想法（脱敏）
- 是否完成「提议 → 确认 → PubMed」
- 是否放弃（及原因）
- 人工 override 次数
- AI 错误 / 信任失败案例

## 成功信号（PRD §45）

> 「我本来想做 A，它告诉我 A 已经做得差不多了，然后帮我找到了 B；而 B 正好是我们科室有数据、也真正能做的。」

## 失败信号（PRD §46）

- 觉得聪明但不回来
- 只当更好的 PubMed 界面
- 不信任证据溯源

## 你需要准备

- [ ] 可安装的 macOS .dmg（或 install.sh 指向的 Release）
- [ ] 1 页纸安装说明（含「右键打开」未签名应用）
- [ ] NCBI / DeepSeek 密钥填写说明
- [ ] 反馈表单（飞书/问卷星即可）
